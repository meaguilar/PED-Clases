# Programación de Estructuras Dinámicas

Este repositorio contiene una colección de **ejercicios, ejemplos como recursos de apoyo** desarrollados durante las clases de la asignatura **Programación de Estructuras Dinámicas**.

Su propósito es servir como material de consulta para reforzar el aprendizaje **teórico-práctico**, facilitando la comprensión de los conceptos fundamentales mediante ejercicios y ejemplos de programación.

## 📚 Temas de estudio

A lo largo de la asignatura se abordarán los siguientes temas:

* **Estructuras de datos estáticas**

  * Conceptos fundamentales.
  * Arreglos y structs
  * Operaciones básicas sobre estructuras estáticas.

* **Punteros**

  * Concepto y funcionamiento.
  * Declaración y manipulación de punteros.
  * Aritmética de punteros.
  * Uso de punteros en estructuras de datos.

* **Referencias**

  * Concepto de referencia.
  * Diferencias entre referencias y punteros.
  * Uso de referencias en la implementación de estructuras de datos.

* **Estructuras de datos dinámicas lineales**

  * Listas enlazadas.
  * Listas simples y doblemente enlazadas.
  * Pilas.
  * Colas.
  * Operaciones de inserción, eliminación y recorrido.

* **Estructuras de datos estáticas no lineales**

  * Conceptos fundamentales.
  * Árboles y otras estructuras no lineales.
  * Representación y operaciones básicas.


> **Nota:** Los ejercicios incluidos en este repositorio tienen un propósito principalmente educativo y pueden ser utilizados como referencia para el desarrollo de prácticas y actividades de la asignatura.
